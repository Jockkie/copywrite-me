# Channel check: always live

Platforms change what they reward, their character limits and their rules often. This file lists what to check, not the answers. Look up the current answers every time.

## How to check

1. Search, with the current month and year: "<platform> <format> best practices", "<platform> algorithm <year>", "<platform> character limit <format>", "<platform> ad policy <sector>".
2. Prefer official sources first (the platform's help center, creator or business blog, ad policies), then recent analyses from reputable marketing sources. Note publication dates; ignore anything older than about a year for algorithm claims.
3. Summarise in five to eight lines with date and source. Say plainly where sources disagree.
4. If you cannot search, say so, and give the user the checklist below to verify themselves.

## What to verify per format

| Format | Check |
|--------|-------|
| LinkedIn post or carousel | Length, how many lines show before "see more", link handling, document or carousel specs, posting frequency, what counts as engagement bait |
| Instagram post, carousel, reel caption | Caption length, characters before truncation, slide count and ratio, hashtag guidance, reel length |
| TikTok or Shorts script | Hook window, ideal length, on-screen text, captions |
| X post or thread | Character limit for the account type, link handling, thread structure |
| Email (newsletter, sales, cold) | Subject line length on mobile, preview text, spam triggers, cold email rules and laws (consent, unsubscribe), plain text vs designed |
| Landing or sales page | Above-the-fold elements, page speed, mobile reading, accessibility, form length |
| Search ads | Headline and description limits, ad policies for the sector |
| Social ads | Text limits, policy for the sector, special ad categories |
| Product description (shop, marketplace) | Marketplace rules, title limits, keyword guidance |
| Substack or blog | Title and subtitle, SEO title length, preview, readability |
| Google Business profile | Description limit, post types, prohibited content |

## Accessibility (always)

Short paragraphs, descriptive link text, alt text for images, no meaning carried by colour alone, readable contrast in visuals, captions on video, no text locked inside images without an alternative.
